🔍 How Bridge Access Control Works

  1. Resource Protection: The bridge interface is protected by the bridge_demo resource
  2. Permission Requirements: Users need write level access with bridge_execute scope
  3. Provider Registration: Bridge providers register routes with specific trust scores and fees
  4. Route Discovery: Users can discover optimal routes based on cost, speed, or reliability
  5. Instruction Compilation: Bridge requests become deterministic instructions on WSTFChain
  6. Off-Chain Execution: Bridge runners monitor events and execute actual cross-chain transfers
